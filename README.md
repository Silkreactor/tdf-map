# TDF working atlas — v5.2

[Open the public review map](https://silkreactor.github.io/tdf-map/).

The approved branching Domains & Roles map is restored as the opening view. The other four maps keep their concrete inventory but begin at an overview: choose a branch, then an item, then evidence. Click or keyboard/touch opens details; hover/focus previews are optional. Existing assets, named relationships, unknowns and proposals remain explicitly distinguished. All five maps have paired Markdown.

This is a dated review snapshot, not an official organisation chart, live monitor, approved proposal, funding recommendation or attendance roster. A technical contact is not automatically an administrator. Listed roles need current confirmation. Funding leads retain their source-check dates, not a claim that they are currently open or eligible.

This repository and every file in it are public. Only the reviewed public projection is included: professional first-name context, safe system descriptions and named research leads. No passwords, internal addresses, raw transcripts, private people profiles, booking/customer data or detailed operational incident records belong here. The fuller private edition is hosted separately with authentication; it is never stored in this repository.

Version v5.2 restores the accepted domains interface rather than replacing it with a uniform renderer. Initial prose is reduced in the four supporting maps through progressive disclosure, not by deleting knowledge. Do not redesign the approved domains layout without Jaggy's permission. Earlier commits and the dated original reading view remain recoverable history, not current factual truth. Publication and tests do not establish human acceptance; use a map for one real question and report what is wrong or missing to Jaggy.
