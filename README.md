# TDF working atlas — v5.1

[Open the public review map](https://silkreactor.github.io/tdf-map/).

Five maps: actual digital infrastructure, domains and responsibilities, people and access, AI/technology income possibilities, and regenerative finance. Start with existing assets and source-linked relationships; unknowns and proposals remain explicitly marked. Select a node for evidence, open questions and related maps. Search, work-area filters, zoom, a readable list and paired Markdown are available.

This is a dated review snapshot, not an official organisation chart, live monitor, approved proposal, funding recommendation or attendance roster. A technical contact is not automatically an administrator. Listed roles need current confirmation. Funding leads retain their source-check dates, not a claim that they are currently open or eligible.

This repository and every file in it are public. Only the reviewed public projection is included: professional first-name context, safe system descriptions and named research leads. No passwords, internal addresses, raw transcripts, private people profiles, booking/customer data or detailed operational incident records belong here. The fuller private edition is hosted separately with authentication; it is never stored in this repository.

Version v5.1 restores the concrete inventories that v4.1 over-condensed. Earlier commits remain recoverable history, not the current view. Please do not use old snapshots as current source truth. Publication and tests do not establish human acceptance; use the map for one real question and report what is wrong or missing to Jaggy.
